Sidequests by Robin Pieterse

Things I build after the main quest.

I'm a solutions architect in Johannesburg, working with Microsoft 365 and Azure. My day job is helping organisations plan and run their Microsoft environments.

These are the tools I build on the side, mostly to make that environment easier to see. They're free, open source, and need no sign-in.

Quests

Live tools you can use right now.

Constellate

Live

An interactive star chart of Microsoft 365. Each service is a constellation: zoom in to see its features, which plans include them, and links to the official documentation. Filter by plan to see what a licence actually gets you.

M365 Change Radar

Live, updated daily

One searchable list of everything Microsoft has changed across 365, Entra, Azure and Graph. It pulls from the public roadmap, Azure Updates, Microsoft blogs, and the Graph and SDK changelogs, and rebuilds every morning. Filter by product, source, or what's rolling out or retiring.
